A personal portfolio for Dr. Pumla Nofemele, showcasing work across four areas:

Cybersecurity & Digital Safety
Research & Communications
UX Research & User Experience
Web Design

Features
Warm cream, blush and nude colour palette with an elegant serif and sans-serif type pairing
Four skill cards and four project categories in a 2×2 layout
Click a category to view its projects, with a back button to return
Subtle motion: slowly rotating asterisk, scroll-in animations, a scrolling specialties band and card hover effects
Fully responsive across laptop, tablet and mobile
Respects “reduce motion” accessibility settings

SEO ready: meta description, canonical URL, Open Graph and Twitter/X card tags

Built with
HTML5, CSS3 (Grid, Flexbox, custom properties) and vanilla JavaScript
Instrument Serif and Manrope from Google Fonts
Font Awesome 6 icons
Hosted on Netlify
