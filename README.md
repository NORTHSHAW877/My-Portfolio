A bold, modern portfolio website featuring a vibrant red color scheme with neon accent effects. Built with pure HTML, CSS, and vanilla JavaScript for optimal performance and easy customization.
🎨 Features

Responsive Design - Fully mobile-friendly layout that adapts to all screen sizes
Smooth Scrolling Navigation - Seamless section transitions with anchor links
Neon Hover Effects - Eye-catching neon yellow and green glows on interactive elements
Grid Layouts - Dynamic, asymmetric grid systems for portfolio showcases
Parallax Floating Text - Subtle depth effects with scroll-based animations
Three Portfolio Sections:

Writing - Showcase articles and blog posts with images, descriptions, and links
Instructional Design - Display educational projects and learning experiences
Web Design - Feature web development work with visual previews
